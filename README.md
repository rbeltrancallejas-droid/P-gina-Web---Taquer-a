# Página Web - TAQUERÍA LOCAL

Proyecto desarrollado para la materia de Taller de Sistemas Operativos.

## Descripción

Página web estática para un negocio de comida (Carne Asada y Aguas Frescas).  
Incluye:

- Tarjetas interactivas de productos
- Modal dinámico con descripción y precios
- Animaciones al hacer scroll
- Botón para volver arriba
- Diseño moderno y responsive

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript 

## Frameworks Usados
- Bootstrap
